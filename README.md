# Meteora DLMM Telegram Bot

Telegram bot for managing Meteora DLMM positions with inline keyboard buttons.

## Features
- Password-protected access
- View positions
- Withdraw liquidity + claim fees (no auto-swap)
- Manual swap via Jupiter v2

## Setup
```bash
npm install
cp .env.example .env  # fill in your credentials
npm run build
npm start
```
